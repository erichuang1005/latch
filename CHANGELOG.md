# Changelog

## 0.1.0

First cut of the Latch catalog.

- ConfirmCard, ClarifyForm, HandoffCard, ThinkingSteps, ChoiceList, ItemSummary, StatusPill, Toast, and Citation.
- A2UI adapter for v0.9.1 envelopes and v0.8 streams, with Zod schemas and example messages.
- Docs site, principles, research notes, and a scripted offsite demo that runs without an API key.
- Optional model route sample behind `LATCH_LLM_API_KEY`. Not mounted on the static site.
